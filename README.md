# Personal Job Application Tracker

A simple command-line application built using Python to manage and track job applications across different companies and recruitment stages.

This project helps users organize their job search, monitor application progress, search applications, and generate useful summaries.

## Project Overview

The Personal Job Application Tracker allows users to maintain records of job applications with details such as:

* Company name
* Job role
* Application status
* Application date

It tracks applications across four stages:

* Applied
* Interview
* Selected
* Rejected

## Features

* Add Applications: Add new job applications with company, role, status, and application date.
* View Applications: Display all stored job applications.
* Search by Status: Find applications based on their current recruitment stage.
* Search by Company: Search applications using company names.
* Update Status: Update an application’s status as the recruitment process progresses.
* Generate Summary: Calculate the number of applications in each status.
* Track Interviews: Identify companies and roles currently at the interview stage.
* Save Data: Store application records using JSON.
* Generate Reports: Export application details and summaries into a text file.
